# Payhawk Invaders

A tiny browser game in the style of Chrome's offline dinosaur game crossed with Space Invaders.
A Payhawk card shoots `$` at falling business expenses; the score is the total value of expenses shot.

Play it: https://aleksandrenko.github.io/payhawk-invaders/

- ← → move, SPACE shoot, hold SPACE to top up the empty clip (24 shots), P pause, M mute
- Later waves bring pricier expenses and double-size items that need two hits
- Single `index.html`, no dependencies
